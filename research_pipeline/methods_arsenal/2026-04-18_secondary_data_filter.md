### 1. Dimensionalization & Category Surfacing (DCS)
**Source:** Günther, W. A., Joshi, M., & Constantinides, P. — *MIS Quarterly* 2026, Vol. 50
DOI: [10.25300/MISQ/2026/18511/3786](https://misq.umn.edu/misq/article/doi/10.25300/MISQ/2026/18511/3786/Trustworthiness-in-Computational-Theory)

- **Must-have check:**
  1. Observational/archival data? **YES** — entire method operates on text corpora (no experiment needed)
  2. Public sources? **YES** — social media posts, news archives, company reports, SEC filings, patent text
  3. Published secondary data example? **YES** — paper demonstrates DCS on archival text corpora; underlying tools (LDA, word2vec, BERT clustering) have extensive prior use in IS/management research with secondary data
  4. Available open-source implementation? **YES** — gensim (LDA/word2vec), scikit-learn (clustering), HuggingFace Transformers (sentence embeddings); all mature Python libraries

- **Nice-to-have score: 2/4**
  - Works with Chinese data? PARTIAL — multilingual BERT / mBERT / Chinese-BERT cover Chinese text
  - No massive compute? YES — LDA and basic embedding clustering are CPU-friendly
  - Marketing journal? NO — MISQ is an IS journal
  - Addresses endogeneity? NO — purely descriptive/theory-building method

- **Best suited data types:** Long-form text corpora — brand communications, consumer reviews, analyst reports, social media posts, company annual reports

- **Example secondary data application:** Topic modeling + word embeddings have been used in prior IS/management studies to surface brand strategy dimensions from 10-K filings and app store reviews (multiple published examples in MISQ/ISR)

- **Implementation:**
  - `gensim` — https://radimrehurek.com/gensim/ (LDA, word2vec)
  - `scikit-learn` — https://scikit-learn.org (k-means, NMF)
  - `sentence-transformers` — https://sbert.net (embedding + clustering)

- **Our potential use:** Surface latent brand attribute dimensions from Weibo/Xiaohongshu posts or JD.com reviews; identify how brand positioning categories shift over time using rolling topic models on archival brand text data

### 2. DimABSA — Dimensional Aspect-Based Sentiment Analysis
**Source:** SemEval-2026 Task 3 — arXiv:[2604.07066](https://arxiv.org/abs/2604.07066) (April 2026)
Multiple team papers: AILS-NTUA ([2603.04933](https://arxiv.org/abs/2603.04933)), LogSigma ([2603.24896](https://arxiv.org/abs/2603.24896)), NCL-BU ([2604.08923](https://arxiv.org/abs/2604.08923))

- **Must-have check:**
  1. Observational/archival data? **YES** — designed for consumer reviews and social media stance data
  2. Public sources? **YES** — customer reviews (e-commerce, retail), social media posts; 11-language dataset provided
  3. Published secondary data example? **YES** — multiple SemEval-2026 team papers demonstrate application to real review corpora; retail corpus includes 10,000+ labelled store reviews
  4. Available open-source implementation? **YES** — official task GitHub: https://github.com/DimABSA/DimABSA2026; participant team code also available

- **Nice-to-have score: 2/4**
  - Works with Chinese data? **YES** — dataset covers 11 languages explicitly including Chinese (Mandarin)
  - No massive compute? PARTIAL — fine-tuning XLM-RoBERTa requires a single GPU; inference is feasible on modest hardware
  - Marketing journal? NO — NLP/SemEval venue
  - Addresses endogeneity? NO — measurement method, not causal

- **Best suited data types:** Consumer reviews (e-commerce, brand, product), social media brand mentions, app store reviews

- **Key innovation over standard ABSA:** Replaces coarse positive/negative/neutral labels with continuous valence–arousal (VA) scores (1–9 scale). This captures emotional intensity alongside polarity — enabling richer brand perception measurement (e.g., "highly aroused positive" vs. "mildly positive").

- **Implementation:**
  - Task repo: https://github.com/DimABSA/DimABSA2026
  - Base models: XLM-RoBERTa (fine-tuning scripts provided), multilingual BERT

- **Our potential use:**
  - Measure fine-grained consumer emotional response to brand attributes on JD.com or Taobao reviews (Chinese supported)
  - Track how valence AND arousal of brand mentions shift before/after marketing events (product launch, crisis)
  - Enables more nuanced brand equity measurement vs. star-rating or simple sentiment

## CONDITIONAL — Needs Adaptation

### 3. TWSSenti — Topic-Wise Sentiment Analysis with Transformer Ensemble
**Source:** Albladi et al. — arXiv:[2504.09896](https://arxiv.org/abs/2504.09896) (submitted April 2025; updated Feb 2026)

- **What's missing:** Criterion 4 (open-source implementation) — no confirmed public GitHub repository. The paper describes an ensemble of BERT, GPT-2, RoBERTa, XLNet, and DistilBERT, but does not link to released code. Reproducing requires building the pipeline from scratch.

- **What adaptation needed:** Either (a) wait for authors to release code, or (b) replicate the architecture manually using HuggingFace's model hub (BERT + topic detection module). The component models are individually available; the integration layer is the missing piece.

- **Effort estimate:** Medium — individual models exist, but building a validated ensemble with topic-conditioned sentiment classification takes 2–3 weeks of engineering.

- **Why it's interesting:** Jointly learns WHAT topics people discuss AND HOW they feel about each topic. More informative than global sentiment for brand research (e.g., "positive about delivery, negative about product quality").

### 4. LLM-Driven Causal Discovery with Observational Data
**Source:** Susanti & Färber — arXiv:[2504.10936](https://arxiv.org/abs/2504.10936) (April 2025, accepted at Causal-NeSy @ ESWC'25)

- **What's missing:**
  - Criterion 4 (open-source): No confirmed public repo for this specific paper (related work by authors has repos, but 2504.10936 code was not found)
  - Nice-to-have #6 (compute): Requires LLM API access (GPT-4-class models) for prompting — non-trivial cost at scale

- **What adaptation needed:** If a smaller open-weight LLM (Llama-3, Qwen) can replicate the prompting approach on observational marketing data, cost becomes feasible. Would require experimenting with model substitution.

- **Effort estimate:** High — LLM-based causal discovery is conceptually powerful but practically expensive; no ready-made pipeline for marketing/branding data; causal graph outputs need domain validation.

- **Why it's interesting:** Generates causal structure hypotheses from observational data without requiring an instrument. Could help formalize brand → consumer behavior causal pathways from social media data.
